# Пять экспериментальных сайтов

Витрина работ: WebGL и шейдеры, скролл-сценарии, кастомные курсоры и загрузчики.
Каждый проект — один самодостаточный `index.html`. Без сборки, без фреймворков,
без `node_modules`: внешние зависимости подключаются только с CDN.

**Живая версия:** https://token1267.github.io/

## Проекты

| # | Проект | Что внутри | Технологии |
|---|--------|-----------|------------|
| 01 | [Lumora](lumora/) | Прелоадер `000→100`, «жидкая кисть» в герое, пружинные появления | Lenis, Canvas 2D, rAF-пружины |
| 02 | [Laocoön — Bronze and Time](laocoon/) | Бронзовая статуя, облёт камеры на 360° по скроллу, шейдер жидкого металла, 450 искр | Three.js r160, GLSL, GLTF |
| 03 | [Loopstack](loopstack/) | Один неподвижный экран, видео-фон, побуквенный въезд вордмарка, стеклянный курсор | CSS-анимации, video, custom cursor |
| 04 | [NEON-NEXUS](neon-nexus/) | Boot-загрузчик, сетка-«фонарик» на канвасе, глитч-ховеры, магнитная кнопка | Canvas 2D, Lenis |
| 05 | [AURA ESTATES](aura-estates/) | Текст-маска с фото внутри букв, горизонтальный скролл на `sticky`, контр-параллакс | Lenis, sticky, parallax |

## Как смотреть

Открыть корневой `index.html` — это витрина. Наведение на карточку подгружает
живое превью проекта в уменьшенном `iframe`, клик открывает проект на весь экран:
`←` / `→` переключают проекты, `Esc` закрывает.

Эффекты завязаны на курсор, поэтому смотреть лучше на десктопе.

## Локальный запуск

Достаточно открыть `index.html` в браузере — сборка не нужна.
